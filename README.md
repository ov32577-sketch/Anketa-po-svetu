# Анкета «Свет в ваших проектах»

Анкета для студентов-дизайнеров перед встречей в шоуруме Maytoni.

- `index.html` — страница анкеты
- `config.js` — адрес Google Apps Script, куда отправляются ответы
- `assets/` — логотип и шрифты

Ответы хранятся в Google Таблице организатора, а не в этом репозитории.
